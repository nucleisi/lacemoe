# [lace.moe](https://lace.moe)

my personal website. built with html, css, a little bit of js, and a bunch of trial and error. 

deployed via cloudflare workers! constantly updated :3

## pages
- **main** — landing page
- **about** — who i am and stuff
- **interests** — things i like
- **rambling** — blog-ish thing
- **art** — gallery of drawings
- **music** — some songs i like + last.fm widget
- **links** — other places to find me

## structure
- `assets/` — images, favicon, etc
- `music/` — mp3 files for the music page
- `art/` — images for the art gallery
- `style.css` — all the styles
- `wrangler.toml` — cloudflare config
